# poisson

Prepared Harbor task package. This is not a completed formal trial. Public build context contains only the six dev inputs and public checker/client. Use the trusted controller, register evaluate/finalize, close research, then configure `runner.harbor_verifier:ResearchReplayVerifier`. The default test.sh intentionally fails so generic Harbor invocation cannot emit an unverified reward. G1/G2/G3 guidance comes from the separate prompts directory. Final data, generator, GT and baselines are absent.
